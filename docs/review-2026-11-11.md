# Independent LLM review #1 (2026-11-11)

**What this is.** An independent review by a language model, **not a human
reviewer**: a cold session of the strongest LLM available to the owner,
outside the project, given an adversarial brief (find where results are
inflated, where a metric measures the wrong thing, where a criterion was fitted
to the result, what breaks on the next video). It reviewed a snapshot of `main`
before the sealed T6 run. The specification places an "external audit" before
T6 so that its findings can still be fixed and the pipeline refrozen; this
review is what filled that place.

The findings below are summarised in our words, not the reviewer's text. The
reviewer ordered its fixes by what cannot be repaired once T6 has been seen:
(1) write the T6 interpretation rule now; (2) freeze the metric; (3) a human
check of the T6 reference; (4) run T6 from a clean checkout of a tag; (5)
pre-register a translation check on T6. All except (3) were done in one
session on 2026-11-11 (`pipeline-v3`, commit `d180a73`).
